# gitRelease [![Build Status](https://jenkins.craftingit.de/buildStatus/icon?job=kstruessmann%28GitHub%29%2FgitRelease%2Fmaster)](https://jenkins.craftingit.de/job/kstruessmann(GitHub)/job/gitRelease/job/master/)

## Usage

### Github
```` sh
bash-3.2$ gitrelease github
gitRelease 0.1.0
Copyright (C) 2020 gitRelease

  create          Creates a new Release

  update          Updates a present Release

  upload          Upload a asset

  updateBody      Updates a present Release

  isDraft         is the release a draft?

  isPrerelease    is the release a Prerelease?

  help            Display more information on a specific command.

  version         Display version information.
````

### Gitea
```` sh
bash-3.2$ gitrelease gitea <URL>
gitRelease 0.1.0
Copyright (C) 2020 gitRelease

  create          Creates a new Release

  update          Updates a present Release

  upload          Upload a asset

  updateBody      Updates a present Release

  version         Display version information.
````
